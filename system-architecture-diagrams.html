20. 关键设计决策

#决策理由影响
1Cookie 而非 Bearer JWT浏览器自动携带 · HttpOnly 防 XSS · 无需前端手动管理需要 CSRF 双重保护机制
2权限码运行时计算并缓存get_current_user 中一次四表 JOIN → _permission_codes Set每次请求 1 次 SQL 查询 · O(1) 权限检查
3Agent 运行所有权隔离所有 Agent 资源按 owner_user_id 限定，404 区分不存在数据安全 · 审计追踪 · 零信任模型
4SSE 双路径传播DB NOTIFY + 内存 EventBus 并行，同时支持进程内和跨进程单机和多机部署均可用 · 容错
5Worker 租约机制原子认领 + 定时续期 + 过期自动回收防重复执行 · Worker 宕机自动恢复
6前端全 CSR（无 SSR）所有页面 "use client" · API 层独立简单部署 · 但首屏依赖 JS
7纯 React 状态（无状态库）无 Redux/Zustand · useState + DOM Events + Map 缓存学习成本低 · 大量 prop drilling
8增量流式 Markdown 解析Fence-aware 分块 · 代码块不拆分 · committed + pending tail实时渲染体验 · 边接收边显示
9思考安全过滤正则阻止 JSON/代码块 · 安全关键词检测 · 回退中文短语防止 LLM 输出泄露敏感信息
10软删除 + 定时物理清理RBAC 软删除(is_deleted) · Agent 定时清理(90/180天)可恢复操作 + 存储成本控制
